# COURSEWORK-Assigment-Tracker-and-Task-Manager

INTRODUCTION

COURSEWORK is a class management and productivity platform designed to help students and class incharges organize academic tasks, reminders, study materials, and class information in one place.

TASK MANAGEMENT

- Add Tasks: Class incharges can create tasks and assignments with descriptions and due dates.
- File Attachments: Tasks can include attached files such as documents, worksheets, PDFs, and other study-related resources.
- Due Date Tracking: Students can easily view upcoming tasks and keep track of their deadlines.

REMINDERS

- Set Reminders: Users can create reminders to keep track of important academic activities and deadlines.
- Personal Reminders: Students can also create private reminders that are visible only to them.

STUDY MATERIAL

- Share Study Material: Class incharges can upload and organize study materials for the class.
- Easy Access: Students can browse, preview, and download shared materials from the platform.

CLASS DASHBOARD

- Class-Incharge Managed: The shared class dashboard is managed by class incharges, who can post tasks, reminders, study materials, events, and other class information.
- Personal Workspace: Students can maintain their own private tasks and reminders alongside the shared class content.
- Private Data: Personal tasks and reminders remain private to the individual student and are separate from the shared class dashboard.
